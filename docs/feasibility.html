F. Cross-cutting caveats

GDPR

Storing posts and author names counts as processing personal data. You need a legitimate-interest basis, a retention policy and a way to handle deletion requests. Get this signed off internally if it's for SBS.

No backfill

Your history starts the day you switch it on. Most APIs only look back days or weeks.

Maintenance

APIs change, scrapers break and quotas move. Expect a few hours a month of upkeep. Claude Code makes the fixes fast, but someone has to notice the breakage.

Running costs

LLM classification is cheap per mention with small models. Paid APIs (X, news, search results) are the real cost. Many sources still cost nothing.

Bottom line

Tier 1 · Build first

AI visibility tracker

Use Semrush keywords to choose the prompts. Track ChatGPT, Perplexity, Gemini, Claude and AI Overviews.

Clearly worth it: fully possible, cheap, close to your content and SEO work.
Tier 2 · Build next

Focused listening

News, blogs, Reddit, YouTube, HN and reviews, with Claude sentiment, intent and topics, a weekly briefing and Slack alerts.

Worth it for B2B. Covers most of the conversations that matter in your market.
Tier 3 · Don't build

Closed platforms

Instagram, TikTok, LinkedIn and Facebook listening, or vendor-scale crawling.

Pay a vendor if you need these. If it offers an MCP server or API, run Claude analysis on top.
