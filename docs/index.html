SBS Watch

In-house brand monitoring and AI-visibility tracking, built with Claude Code. We build the parts we can own, starting with the parts that pay off first.

News monitor Feasibility map PDF version Repository

Why this exists. Commercial social-listening tools combine data collection, AI analysis and reporting. Claude Code can build almost all of the analysis and reporting. Data access is the limit: news, blogs, Reddit, YouTube and reviews are within reach, while Instagram, Facebook, TikTok and LinkedIn are closed.

So we start where data access isn't a problem: tracking how AI assistants talk about us and our competitors.

Roadmap

Phase 0 · Feasibility and workspace

Done

Feasibility map of 33 social-listening features, this site and the shared repository.

Phase 1 · AI visibility tracker

Up next

Run a set of buyer prompts against ChatGPT, Perplexity, Gemini and Claude on a schedule. Track mentions, rank, share of voice and cited sources against competitors. Prompts come from Semrush keywords and our personas.

Phase 2 · Focused listening

Started

News monitoring is live: daily Google News headlines for SBS and competitors in English and French. Still to come: blogs, Reddit, YouTube, Hacker News and reviews, with Claude sentiment, intent and topics, a weekly briefing and Slack or Teams alerts. Sources with personal data (Reddit, reviews) need a GDPR review and a private dashboard first.

Phase 3 · Closed platforms

Decide later

Instagram, Facebook, TikTok and LinkedIn can't be built in-house. If we need them, we buy a vendor and run Claude analysis on top.

How we work

Issues for tasks

Every piece of work starts as a GitHub issue, so everyone can see what's in progress and who owns it.

Pull requests for changes

Work on a branch and open a pull request. One teammate reviews before it merges into main.

This site updates itself

Anything merged into the docs/ folder on main is published here within a minute or two.

Ground rules: this repository is public

No secrets

API keys and tokens go in GitHub Actions secrets or a local .env file, never in commits.

No personal data

No collected posts, author names or raw mentions. Only code and aggregated results.

No confidential material

No customer names, internal figures or anything you wouldn't post publicly.
